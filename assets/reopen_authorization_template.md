# Reopen Authorization Record

Paste-ready template for `outputs/REOPEN_AUTHORIZATION_RECORD.md`. Required for any `SEARCH_AMEND` node parented to `SEARCH_CLOSED_NO_NEW_BASELINE`. Without this file quoting an explicit reopen instruction, the amendment is labeled `REOPEN_REQUIRES_EXPLICIT_USER_INSTRUCTION` and refused. See `core_protocol.md §22`.
